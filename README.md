# C++ Linked List Implementation

A simple C++ project demonstrating the implementation of a **Singly Linked List** using dynamic memory allocation and pointers.

## 📌 About the Project

This project demonstrates how a linked list works in C++. It allows the user to create a linked list by entering the number of nodes and their data.

Each node contains:

* `data` — Stores an integer value.
* `next` — Stores the address of the next node.

## ✨ Features

* Create a singly linked list.
* Insert nodes at the end of the list.
* Display all node values.
* Use pointers to connect nodes.
* Allocate memory dynamically using `malloc()`.
* Release allocated memory using `free()`.

## 🛠️ Technologies Used

* **Language:** C++
* **Concepts:** Data Structures, Pointers, Structures, Dynamic Memory Allocation
* **Compiler:** GCC (MinGW)

